# Security policy

Do not disclose credentials, API tokens, authentication keys, private network inventory, router exports, actual WAN endpoints, hardware serial numbers or unredacted logs in issues, pull requests or commits.

For a potential vulnerability in repository examples, use GitHub private vulnerability reporting if the feature is enabled. Otherwise request a private reporting channel using a non-sensitive issue summary.

Example private IP networks and `example.test` names are reference-only. Scrub screenshots, file metadata, commits and diagram labels before publishing.
