# Sanitized configurations

This directory will contain **tested, redacted examples**, not entire production exports.

Use `nas01.example.test`, documentation-only public addresses such as `198.51.100.10`, and illustrative private subnets such as `10.10.30.0/24`. Store sensitive values in an appropriate secrets manager.

Never commit actual router configurations, authentication cookies, VPN tokens, private keys, device serials, or internal logs.
