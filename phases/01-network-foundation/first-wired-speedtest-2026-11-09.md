# First GT-BN98 Pro wired speed test — 2026-11-09

The new ASUS GT-BN98 Pro is online through LiveOak Fiber and the Calix GP1101X. A Windows 11 laptop negotiated a 1.0 Gbps Ethernet link and produced this user-reported Speedtest result:

- Download: **933 Mbps**
- Upload: **942.46 Mbps**
- Reported ping-related readings: **20 / 49 / 33 ms** (likely idle/download-loaded/upload-loaded; not independently confirmed)
- Speedtest displayed five dots in each reported application category.

These are strong results for a 1GbE client and do not validate end-to-end 5 Gbps service. Next: verify negotiated ONT-to-router WAN link speed (10GbE target); if supported, run router-side speed test or use a multi-gig-capable wired client.
