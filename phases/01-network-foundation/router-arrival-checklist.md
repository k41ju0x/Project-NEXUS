# GT-BN98 Pro installation plan

Status: router ordered; delivery pending. Do not mark installed until verified.

## Purchase candidates
- QNAP QSW-M2108-2C: managed 8x2.5GbE + 2x10GbE combo switch.
- CyberPower CP1500PFCLCD: 1500VA/1000W UPS, size to measured load.
- Three to five Cat6a patch cables and labels.

## Install
1. Back up existing ASUS configuration privately.
2. Stage new ASUS offline and update firmware.
3. Move ONT Ethernet to router 10GbE WAN.
4. Verify WAN negotiation, DHCP, Wi-Fi, DNS and IPv6.
5. Test speed using capable wired client, then add switch via 10GbE LAN.
6. Keep old router available for rollback.

Do not publish network identifiers, serial numbers, configuration exports, or credentials.
